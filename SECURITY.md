# Security

Please do not report security problems in a public issue.

Use **Report a vulnerability** on this repository's [Security tab](https://github.com/mcgeand/gapscout-app/security/advisories/new) instead. The report stays private between you and the maintainer until a fix is out.

Include the GapScout version (Help → About), your OS, and the steps that show the problem. You should hear back within a week.

Only the latest release is supported.
